# Mohammed Yasser Mohammed - Portfolio

## Open the website
Double-click `index.html`. It opens in your browser. No install needed.

## Edit your name and info
Open `index.html` in Notepad or VS Code. Search (Ctrl+F) for your text, change it, save, and refresh the browser.

## Replace the profile picture
1. Pick a clear, square-ish photo of your face.
2. Rename it to `profile.jpg`.
3. Put it next to `index.html` and replace the old file.
If the photo is missing, a "MYM" placeholder shows instead.

## Change portfolio projects
In `index.html`, find `PORTFOLIO`. Each `<article>` is one project. Change the title, text, and category. Change `href="#contact"` to your project link. To add an image, put it next to `index.html` and replace the `<span>Placeholder</span>` line with `<img src="project1.jpg" alt="Project name">`.

## Change colors
Open `style.css`. At the top, edit the values under `:root` (for example `--cyan` and `--purple`).

## Update WhatsApp and Facebook links
In `index.html`, search for `wa.me`. The format is `https://wa.me/20` + number without the first 0. Example: 01122207606 becomes `https://wa.me/201122207606`. Search for `facebook.com` to change the Facebook link.

## Publish for free
**Netlify:** Go to app.netlify.com/drop and drag the whole `mohammed-portfolio` folder onto the page. You get a free link.

**GitHub Pages:** Create a GitHub account and a new repository. Upload all files. Go to Settings > Pages, choose the `main` branch and `/ (root)`, then Save. Your link appears after a minute.
